09|read|What a machine can read is on the left. Ninety four percent of notices state where and when the product was sold, and ninety four percent state what it cost. Prose becomes checkable facts.
10|decide|And here is the whole design. The verdict engine decides, on dates, on money, on identifiers, and no prompt reaches it. The agent underneath reads one thing: whether a receipt line and a notice describe the same object. It decides nothing.
11|gate|Then the part that matters most. Filing a claim in someone's name cannot be undone, so it passes a hook that cancels it unless the verdict is a match, and a human in the loop gate that waits for the household.

13|veto|Now try to break it. Approve a claim for something the household does not own and order the agent to send it anyway. It refuses. But a model that politely declines proves nothing, so the test calls the tool directly, the way a misbehaving model would.
14|mutation|And here is that check failing on purpose. Delete the hook, and a real claim goes out for a product nobody owns, and the suite goes red. Put it back, and eight hundred and thirty tests pass.
