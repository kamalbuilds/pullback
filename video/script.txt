01|record|This is what the agent sees when it opens a recall notice. Title, description, hazard, remedy, contact. Then the two fields it actually needs. U P C, empty. Model number, empty.
02|receipt|And this is the purchase it is being asked to check. L E D projecting finger lights, party favors, fifty pieces, nine ninety nine, Amazon, July twenty nineteen. Four words in common with the notice. No identifier in either.
03|coverage|That is not one badly written notice. Across all four hundred and thirty four consumer recalls published this year, three percent carry a barcode, and none carry a model number.
04|nbc|Which is why this photograph exists. A recalled infant sleeper, four years after the recall, on a carpet next to a crib. Fewer than one in ten were ever returned.
05|gap|So the problem is not that nobody published. The regulator publishes. The household owns the thing. Nothing crosses the gap between them.
06|carry|What the notices do carry is circumstance. Ninety four percent say where and when the product was sold, and ninety four percent say what it cost. Prose becomes something checkable.
07|decide|And here is the whole design. The verdict engine decides, on dates, on money, on identifiers, and no prompt reaches it. The agent underneath reads one thing: whether a receipt line and a notice describe the same object. It decides nothing.
08|gate|Filing a claim in someone's name cannot be undone. So it passes a hook that cancels it unless the verdict is a match, and a human in the loop gate that waits for the household.
09|run|Here it is on a real purchase. The agent reads the candidates, says what it thinks and why, and is handed a verdict it did not choose. Four checks passed. The claim is written, citing the recall number. Then it stops.
10|veto|Now try to break it. Approve a claim for something the household does not own, and order the agent to send it anyway. It refuses. But a model that politely declines proves nothing, so the test calls the tool directly, the way a misbehaving model would.
11|mutation|And here is that check failing on purpose. Delete the hook, a claim goes out for a product nobody owns, and the suite goes red. Put it back, and eight hundred and thirty tests pass.
12|unattended|None of this needs anyone watching. EventBridge Scheduler runs a Lambda carrying the whole agent, daily. On the second pass: zero cases created, seven updated, because the case id is a hash of the household, the purchase and the notice.
13|breadth|The same engine reads vehicle recalls and food enforcement reports. This household's car matches four real N H T S A campaigns, decided on the model designation, not on any text at all.
14|label|And when the only thing that would settle a case is a code stamped on the object, it asks for a photograph and reads it. When the photograph cannot be read, it says so and asks for a better one, rather than inventing a code.
15|close|Four hundred and thirty four notices this year, and almost none of them carry the one field that would let you check. Pullback reads them anyway, and files the claim.
